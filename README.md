# AI-Resume-Screening-System
A Python-based system to screen resumes using skill matching and calculate job match percentage.

## Project Overview
A Python-based project that compares a resume with a job description using skill-based keyword matching.

## Features
- PDF resume upload
- Resume text extraction
- Matched and missing skills identification
- Resume match percentage calculation
- CSV report generation

## Technologies Used
- Python
- Google Colab
- Pandas
- PyPDF

## How to Run
1. Open the notebook in Google Colab.
2. Upload a PDF resume.
3. Enter the job description.
4. View the screening results.

## Limitation
The match percentage is based on keyword matching and does not represent a complete assessment of a candidate.
